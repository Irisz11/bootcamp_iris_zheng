# Homework 02 — Tooling Setup
This homework sets up a reproducible Python project environment for applied financial engineering. I verified the Python interpreter and package environment, configured local settings with `.env` and `python-dotenv`, created a reusable configuration helper in `src/config.py`, organized the project into a standard directory structure, and verified the environment with a Jupyter notebook and a NumPy operation. The project also records dependencies in `requirements.txt` and uses Git to track reproducible project files while keeping private environment configuration out of version control.
